# Issues

1)  Error: Script Execution was disabled in this system
    Solution: Change Windows Execution Policy to Unrestricted 

2)  Error: npm error enoent ENOENT: no such file or directory, lstat 'C:\Users\Admin\AppData\Roaming\npm'
    Solution: Run "npm install -g npm" command (global npm)
